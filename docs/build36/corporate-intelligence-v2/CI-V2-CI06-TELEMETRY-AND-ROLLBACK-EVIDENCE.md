## Runtime telemetry (metadata only)

`[stylechat-generate] ci_v2` record (closed schema `ci06-telemetry-v1`, validated by `measurement/telemetry.ts`):

| Group | Fields |
|---|---|
| Task / mode | `taskVerb`, `mode`, `register`, `prepared` (or a closed assembly-failure reason), `origin` |
| Validator outcome | `validator`, `stage`, `failureCodes` (closed integrity categories), `fallbackReason`, `copyKey`, `sanitizerCorruption`, `finalizationPasses` |
| Merchants | `eligibleCount`, `labelsRendered`, `registrySource` |
| Tokens | `promptTokens`, `outputTokens`, `thoughtsTokens` summed over attempts from the provider's `usageMetadata`; `providerAttempts`, `providerRetries`, `usageUnreported`, `model` |
| Timing | `elapsedMs` (CI-v2 overhead window from flag resolution to finalization) |
| Flag | `flag` (`on`), and a separate `ci_v2_flag` record `{flag: 'kill_switch'}` as rollback evidence |

Never logged: prompts, conversations, images, user ids, merchant-authored text, merchant names, ownership evidence or
account data. Every string value must be a short code with no spaces, and records that fail the schema are excluded
from aggregation and counted (tested). Plain OFF emits nothing.

Cost is calculated **offline** from token counts and a dated pricing record (`gemini-pricing.2026-07-29`). That record
is older than 90 days on 2026-11-04, so the aggregator marks it `stale`. Re-verify official pricing before quoting
costs.

## Offline measurement

* `telemetry.ts`: schema, pricing, `parseTelemetryLines` + `aggregateTelemetry`. Computes outcomes by
  task/mode/validator/fallback, failure categories, latency p50/p95, tokens, estimated cost mean/p95, eligible counts,
  flag states and rollback records.
* `gateReport.ts` + `runGateReport.ts`: the repeatable G1–G12 report. Thresholds are the proposed Phase 1 values;
  a test checks every number against the contract document. A gate is PASS only if this run measured it or ran its
  governed suite.
