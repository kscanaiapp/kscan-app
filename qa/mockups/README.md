# K Scan AI Mockup Library

## Purpose

This directory contains visual reference assets used by frontend teams when implementing UX/UI updates.

## Rules

- Mockups are visual guidance only.
- Architecture rules always override mockups.
- Security requirements always override mockups.
- Privacy requirements always override mockups.
- Existing backend behavior always overrides mockups.
- Feature flags always override mockups.
- Do not infer functionality from mockups.
- Do not create fake APIs, fake data, fake retailers, or fake commerce flows based on mockups.

## Implementation Workflow

Before any UX/UI build:

1. Review relevant mockup folder.
2. Review existing implementation.
3. Review feature flags.
4. Review architecture constraints.
5. Build.
6. Validate against mockups.
