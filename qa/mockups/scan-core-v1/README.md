# Scan Core V1 Mockup References

## Purpose

These mockups are approved visual references for the Scan Core Construction V1 initiative.

These references document the intended UX direction for:

- Scan Landing
- Camera Scan entry
- Upload Inspiration flow
- Upload Review screen
- Capture Review
- TextScan entry
- TextScan input
- TextScan results
- Scan Results actions
- Save to Style Library handoff
- StyleChat handoff
- Dressing Room handoff
- Scan Again flow

## Important

These mockups are visual guidance only.

They do NOT authorize:

- fake retailer data
- fake pricing
- fake inventory
- fake match percentages
- fake AI results
- fake catalog matches
- fake backend functionality

## Implementation Rules

Engineers must:

- reuse existing Scan architecture
- reuse existing feature flags
- reuse existing save-to-library services
- reuse existing TextScan routes
- preserve backend separation
- preserve Library V2 branch isolation
- preserve Dressing Rooms branch isolation

## Strategic Objective

Scan is the capture wedge.

The purpose of Scan is to convert:

- camera scans
- uploaded inspiration
- text descriptions

into structured fashion intent signals that can later support:

- Style Library
- Dressing Rooms
- StyleChat

without creating fake commerce experiences.
