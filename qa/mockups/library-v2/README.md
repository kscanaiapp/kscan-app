These mockups define the visual direction for Library Room V2.

The Library is the user's personal saved-style workspace. It should organize:

- camera scans
- uploaded inspiration
- saved analysis
- style attributes
- Dressing Room handoffs
- StyleChat handoffs
- backend-ready placeholders for future profile aggregation

## Important Product Boundary

In-app messaging belongs later with Dressing Rooms and shared-room collaboration.
