## 7. Fixes Made

### Fix 1 — Privacy raw error leak
- **File:** `contexts/PrivacyPreferencesContext.tsx`
- **What:** `setRemoteFetchError(error instanceof Error ? error.message : 'Unable to load privacy settings.')` → `setRemoteFetchError('Unable to load privacy settings. Please try again later.')`
- **Why:** Supabase errors like `relation "privacy_settings" does not exist` or `JWT expired` were piped directly to the UI. This leaks backend internals to testers.
- **Severity gate:** 1 file, 2 net lines, no new dependency, no schema change, no native config.
- **Risk:** Negligible — only changes the error string displayed in `InlineNotice`.

### Fix 2 — StyleChat empty session ID guard
- **File:** `app/style-chat/index.tsx`
- **What:** Added `if (!session?.id) return;` after `createSession()` and before `router.push(...)`.
- **Why:** The repository mapper can theoretically return an empty `id`. Without the guard, `router.push('/style-chat/undefined')` would crash the chat detail screen.
- **Severity gate:** 1 file, 1 line, no new dependency, no UI change, no schema change.
- **Risk:** Negligible — only prevents an invalid navigation push.
